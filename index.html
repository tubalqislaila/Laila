Langkah Praktikum Crimping Kabel LAN

1

Kupas Jaket Luar Kabel

Gunakan pisau pemotong pada tang crimping untuk mengupas jaket luar kabel UTP sepanjang kurang lebih 2 cm. Hati-hati jangan sampai memotong isolasi kawat tembaga di dalamnya.

2

Uraikan & Luruskan Kawat

Uraikan 4 pasang pilinan kawat tembaga. Luruskan kawat satu per satu dengan jari agar mudah diatur susunannya.

3

Susun Urutan Warna & Potong Rata

Urutkan warna kawat sesuai standar (T568B atau T568A). Rapatkan kawat lalu potong dengan pemotong tang crimping hingga ujungnya benar-benar rata (sisa ~1.2 cm).

4

Masukkan ke Konektor RJ45

Masukkan 8 kawat sejajar ke dalam konektor RJ45 (posisi pengunci berada di bawah). Pastikan seluruh ujung tembaga menyentuh bagian paling depan konektor.

5

Press / Crimp Menggunakan Tang

Masukkan RJ45 ke dalam mulut crimping 8P pada tang. Tekan gagang tang crimping dengan kuat hingga terdengar suara 'klik' atau pin tembaga menancap sempurna.

6

Pengujian dengan LAN Tester

Colokkan kedua ujung kabel ke Master & Remote LAN Tester. Nyalakan tester dan amati lampu LED 1-8 menyala bergantian secara berurutan.

Konfigurasi Jaringan Peer-to-Peer (2 Laptop)

Langkah-langkah menghubungkan Laptop A dan Laptop B menggunakan kabel LAN secara langsung.

LAPTOP A (Host 1)

Ethernet Adapter
Static IP
IP Address: 192.168.1.1
Subnet Mask: 255.255.255.0
Default Gateway: KOSONGKAN

LAPTOP B (Host 2)

Ethernet Adapter
Static IP
IP Address: 192.168.1.2
Subnet Mask: 255.255.255.0
Default Gateway: KOSONGKAN

Langkah Setting IP Address di Windows

  1. 1

    Buka Network Connections

    Tekan Win + R, ketik ncpa.cpl lalu tekan Enter.

  2. 2

    Pilih Adapter Ethernet

    Klik kanan pada Ethernet / Local Area Connection, lalu pilih Properties.

  3. 3

    Atur Internet Protocol Version 4 (TCP/IPv4)

    Pilih Internet Protocol Version 4 (TCP/IPv4) → Klik Properties → Pilih radio button "Use the following IP address".

  4. 4

    Masukkan IP & Subnet Mask

    Pada Laptop A masukkan IP 192.168.1.1 dan Laptop B masukkan 192.168.1.2. Tekan Tab untuk mengisi Subnet Mask secara otomatis (255.255.255.0).

Panduan Sharing File & Folder di Windows

Langkah praktis membagikan folder antar laptop tanpa flashdisk lewat kabel LAN.

1. Pengaturan Sharing Folder

  1. A. Buat folder baru atau pilih folder yang ingin dibagikan (misal: Data_Sharing).
  2. B. Klik kanan folder → pilih Properties → masuk ke tab Sharing.
  3. C. Klik tombol Advanced Sharing → Centang pilihan "Share this folder".
  4. D. Klik tombol Permissions → Centang pilihan Full Control / Change / Read agar laptop lain bisa membaca & mengisi file.

2. Matikan Password Protection

  1. A. Buka Control Panel → Network and Sharing Center.
  2. B. Klik Change advanced sharing settings di bilah sebelah kiri.
  3. C. Buka bagian All Networks.
  4. D. Pada opsi *Password protected sharing*, pilih "Turn off password protected sharing" lalu klik Save changes.

Cara Mengakses Folder Sharing dari Laptop B

Setelah folder di-share dari Laptop A (IP: 192.168.1.1), ikuti langkah ini dari Laptop B:

Metode Run Command:

Tekan Win + R lalu ketikkan alamat IP Laptop A:

\\192.168.1.1
Metode File Explorer:

Buka File Explorer, ketikkan alamat di atas pada address bar bagian atas lalu tekan Enter untuk membuka berkas.
